# 라벨링 파일럿

프로젝트 루트에서 실행:

```bash
conda activate infohelper
uvicorn RAG_evaluation.labeling.app:app --host 127.0.0.1 --port 8765
```

브라우저: http://127.0.0.1:8765

## 불일치 기준 합의

`/align`에서 0↔2점 불일치 5건을 검토한다. 현재 별도 실행 주소는 http://127.0.0.1:8767/align 이며 같은 실행 명령에 `--port 8767`을 사용한다.

- 비교 파일의 사람·에이전트 점수와 근거, 고정 공고 원문을 함께 보여준다.
- 최종 점수·적용 규칙·판단 이유를 입력하고 저장한다. 보류는 확정 건수에 포함하지 않는다.
- `labeling_pilot_v1/alignment.sqlite3`에 합의 수정 이력을 누적하며 기존 사람 라벨 및 비교 파일은 보존한다.
- 새로고침하면 미확정 항목부터 재개한다. 합의 결과 다운로드에는 원문·양쪽 판정·최신 합의·수정 이력이 포함된다.
- 5건이 끝나면 합의 규칙을 정리하고 나머지 22건에 적용하는 다음 단계를 진행한다.

- Dense·BM25 top 20 합집합에서 유형별 20쌍, 총 120쌍을 선택한다. 유형 내 쿼리별 후보를 고정 시드 해시로 정렬하고 라운드 로빈 방식으로 배분하므로 80쿼리를 모두 포함한다.
- 표본은 첫 실행 때 `RAG_evaluation/artifacts/zighang_v1/labeling_pilot_v1/pilot.json`에 원문과 원본 파일 해시를 저장한다. 이후 실행은 이 스냅샷을 재사용한다.
- 점수 버튼을 누르면 메모·선택한 해석과 함께 같은 폴더의 `labels.sqlite3`에 저장한다. 다시 접속하면 첫 미평가 항목부터 시작한다. 점수를 바꾸려면 이전 항목에서 다시 점수 버튼을 누른다.
- 2=의도와 필수 조건 충족, 1=부분 관련·조건 근거 부족, 0=의도 불일치·필수 조건 위반. 판단 보류는 점수가 아니며 완료 건수에서 제외한다.
- 시간 기준은 2026-09-07이다. Q046의 날짜 경계 모순은 경고하며 경계 사례는 보류한다. corpus 원문과 쿼리는 변경하지 않는다.
- 검색기·점수·순위·정답 후보 힌트는 판정 화면에 노출하지 않는다. LLM 라벨은 아직 만들지 않았다.
- 평가·요약 다운로드에는 모든 저장 판정과 보류·미평가 건수가 포함된다. qrels 다운로드에는 확정된 0·1·2만 포함한다. 미평가와 보류를 0으로 간주하지 않는다. 파일럿 qrels는 전체 3,022쌍의 최종 qrels가 아니다.
- 산출물 폴더는 Git 제외 대상이다. 백업은 서버 종료 후 폴더 전체 복사 또는 화면의 평가·요약 다운로드를 사용한다.
- 한 명이 한 탭에서 사용하는 로컬 도구다. 공개 서버로 배포하지 않는다. 별도 검증에는 `LABELING_OUTPUT_DIR` 환경변수로 저장 폴더를 분리할 수 있다.

검증:

```bash
conda run --no-capture-output -n infohelper python -m pytest test/rag_evaluation/test_labeling.py -q
```
